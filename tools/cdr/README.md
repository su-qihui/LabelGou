# CorelDRAW ↔ LabelGou 衔接说明

本目录随发布包一起分发（`tools\cdr\`）。给的是**店里有 CorelDRAW 那台机器**上的操作步骤。

一句话流程：

> CorelDRAW 里 **文件 → 导出** 成 SVG → LabelGou 里 **模板 → 从底稿导入…（Ctrl+I）** 读进来。

反方向也通：LabelGou **文件 → 导出矢量 SVG…** 出来的件，CorelDRAW 直接打开就能用，
口径是 **1 用户单位 = 1 毫米**，纸张尺寸与标签落位不会漂。

---

## 0. 为什么中间要过一道 SVG

LabelGou **读不懂 `.cdr` 的矢量对象层**。那是 Corel 的专有格式，几何、填充、轮廓的编码没有公开的完整规范——
社区最完整的解析器在自己的源码里写着「从这里开始位置全错，读到的是垃圾」。硬猜的结果是底稿画成一片糊，
比不画还害人，所以我们不做。

SVG 是纯文本 + 公开规范，CorelDRAW 能导，LabelGou 能吃，而且能保住曲线（圆角框、菱形危险品标志、Logo
都是贝塞尔）。所以**保真底稿走 SVG 这一条路**。

`.cdr` 文件直接拖进 LabelGou 也不是完全没用，见第 6 节。

---

## 1. 手动导出（最稳，先认这条路）

1. 在 CorelDRAW 里打开要当底稿的文件。
2. 建议先把**一枚标签**的图形单独放在一页（不要把 20 枚拼在一张大版上导——LabelGou 会问你要标签尺寸，
   对着大版填会填错）。
3. 菜单 **文件 → 导出**（快捷键 `Ctrl+E`）。
4. 保存类型选 **SVG - 可缩放矢量图形**（列表里可能在 "开放格式/网页格式" 分组下，视版本而定）。
5. 文件名随便，位置建议放在专门一个 `底稿\` 文件夹里（LabelGou 会把需要的东西复制进自己的模板目录，
   原文件不动）。
6. 点导出后如果弹出 **SVG 导出选项**，按下表设置：

| 选项 | 建议值 | 为什么 |
|---|---|---|
| 单位 / 精度 | 毫米优先；没有单位选项就不动 | LabelGou 认 `mm/cm/in/pt/pc/px` 与无单位数字，`1px = 1/96in`。**百分比宽高不认**（没有参照物，会告警并忽略） |
| 版本 / 兼容性 | SVG 1.0、1.1 都行 | 都解析 |
| 文本 / 字体 | **不要**「将文字转换为曲线」 | 转曲之后就没有 `<text>` 了，LabelGou 认不出「这是一行可以绑字段的内容」，只能当图形画着。**除非你确定这份底稿一个字都不要改**，那就转曲，导进来更稳 |
| 对象/图层 | 保留即可 | 图层信息 LabelGou 不用，但也不碍事 |
| 位图 / 分辨率 | 300dpi 或更高 | Logo 之类的位图会被原样带进来，太糊会影响人工对版（不影响打印，打印的是矢量部分） |
| 裁切/页面 | 只导标签图形，别把页面框裁切线一起导 | 裁切线进到底图里，会在每枚标签上重复出现一次 |

7. 回 LabelGou：**模板 → 从底稿导入…（Ctrl+I）**，选刚才那个 `.svg`。
8. 导入窗口里会列出识别到的文字，**只有和样例数据对得上的那几行会预先勾上**。逐项确认：
   - 勾 = 这行字提升成可编辑元素，可以绑字段（每次打印随数据变）；
   - 不勾 = 留在底图里，当成图片的一部分，位置尺寸都原样；
   - 绑哪个字段可以在下拉里手选，**程序不猜着绑**。
9. 确认后 LabelGou 会产出：一份**去掉了已提升文字**的规范化底图（存进 `templates\assets\`），加一个 v2 模板。
   原 SVG 一个字都没改，随时可以重导。

窗口里出现的告警（黄字）不是错误，通常是「这个特效不支持所以忽略了」这类，看完点确认就行；
只有红字（打不开、尺寸不合法、超过上限）才会挡住导入。

## 2. 批量导出：用本目录的宏

一份一份点菜单太烦，就 [`ExportSvgForLabelGou.bas`](ExportSvgForLabelGou.bas)。

1. CorelDRAW 里按 `Alt+F11`（或菜单 **工具 → Visual Basic → Visual Basic 编辑器**）。
2. VBA 编辑器菜单 **文件 → 导入文件**，选这个 `.bas`。
   导不进来就 **插入 → 模块**，把 `.bas` 用记事本打开、整段内容粘进去（第一行 `Attribute VB_Name = ...` 粘的时候去掉）。
3. 回 CorelDRAW，菜单 **工具 → 宏 → 运行宏**，选 `ExportSvgForLabelGou.ExportAll`。
4. 宏会把**所有已打开的文档**各导一份，依次尝试 SVG → EMF → WMF → PDF，第一个成功就用它。
5. 产物在 `.cdr` 同目录下的 `<文档名>_LabelGou导出\` 里，另有一份 **`导出清单.txt`**：
   写明这份文档用的哪个格式、失败的是因为什么。报问题时请连这个文件一起发。

> **这个宏没在真机上验证过**（开发机没装 CorelDRAW）。它只用 CorelDRAW 公开 API 名，
> 而且已经做了「三种调用形状依次试」和「失败也写清单」的兜底，但滤镜标识在不同版本里确实不一样。
> 一报错先看下一节；宏用不了就用第 1 节的手动路径，**效果完全一样**。

## 3. 宏报错怎么修

宏的正文不需要动，**九成九只是 `FilterName` 那 4 行的标识写法不合你的版本**。

### 3.1 导入 .bas 时就弹「编译错误: 常数未定义」

这说明你的版本里没有某个滤镜常量名。定位办法：

1. VBA 编辑器里按 `F2` 打开**对象浏览器**，类型库选 CorelDRAW，搜索框输入 `ExportFilter`；
2. 看列出来的成员真名（例如有的版本叫 `cdrSVGExportFilter`，有的叫 `cdrExportFilterSVG`）；
3. 把 `FilterName` 函数里对应的名字改成搜到的那个。

如果对象浏览器里**只有数值常量、或你搜不到**，就直接填数值：在**立即窗口**（`Ctrl+G`）里敲

```
? cdrSVGExportFilter
```

回车，看它打印出来的数字，把 `FilterName` 的返回值改成那个数字即可（这一来要去掉引号，
因为参数要的是数值不是文本）。

### 3.2 运行时报「类型不匹配」，清单里四种格式全失败

同上：滤镜标识该给数值却给了文本。改法见 3.1 末段。

### 3.3 报「对象变量未设置」/ 提示没有正在打开的文档

没打开文档，或这个版本取不到文档列表。先打开一个 `.cdr` 再运行。

### 3.4 报「权限被拒绝」/ 清单里写「没写出文件」

- 输出目录在只读盘或 OneDrive 同步目录里 → 把 `.cdr` 拷到本地磁盘再试；
- `.cdr` 还没存过盘（宏往临时目录写，去 `TEMP` 里找）；
- 导出对话框在等人选选项（个别版本会弹）→ 手动路径更省事。

### 3.5 实在修不出来

不用修。走第 1 节手动导出。这个宏只是省点击菜单的时间，不是流程的必要环节。

## 4. 你的 CorelDRAW 导不出 SVG 怎么办（X3 及更早）

按省事程度排序：

**A. 让装了新版 CorelDRAW / Adobe Illustrator 的机器导一次。**
AI 的 **文件 → 另存为 → SVG** 同样能被 LabelGou 读进来。

**B. 导成 EMF / WMF / PDF，再转成 SVG。**
转换器用 [Inkscape](https://inkscape.org)（免费）的命令行：

```bat
"C:\Program Files\Inkscape\bin\inkscape.exe" --export-type=svg --export-filename="out.svg" "in.emf"
```

批量：

```bat
for %%f in (*.emf) do "C:\Program Files\Inkscape\bin\inkscape.exe" --export-type=svg --export-filename="%%~nf.svg" "%%f"
```

> Inkscape 0.92 及更早版本的参数不一样，用 `--export-svg="out.svg" in.emf`。

**说清楚一件事**：Inkscape 是**你机器上的可选转换工具**，不是 LabelGou 的运行依赖。
装不装它，LabelGou 都还是那个离线免安装、零第三方依赖的单文件程序。

**C. 用 `.cdr` 的缩略图当参考底图，人工重建**（见下一节）。

## 5. 什么样的底稿导进来效果好

做得到就更好，做不到也不至于失败——不支持的东西会告警并忽略，不会崩、不会画错。

**欢迎**：`<path>`（含圆弧 `A`、二次贝塞尔 `Q`、平滑续接 `S/T`）、`<rect>/<circle>/<ellipse>/<line>/<polygon>`、
`<g>` 上的 `transform`（矩阵、平移、缩放、旋转、斜切都认）、CSS `<style>` 与 `class` 选择器、`<use>` 引用、
`fill-rule: evenodd`（「O」「回」这类镂空靠它）、`<image>` 位图、`<text>`/`<tspan>`（含 `dx/dy/x/y` 分段）。

**会被忽略并告警**（告警会一条条写在导入窗口里，说清后果，不会静默画错）：

| 底稿里的东西 | LabelGou 的处理 |
|---|---|
| `<filter>`（阴影/模糊等特效） | 忽略，特效本身不出现 |
| `<clipPath>` / `<mask>` | 忽略；**被它遮住的形状会整份显示出来**（多出本该被遮住的部分）→ 导出前在 CDR 里把裁剪应用到对象 |
| `<pattern>` 图案填充、线性/径向渐变 | 降级为纯色 |
| `%` 单位 | 没有参照物不认，告警 |
| 文字的 `rotate` 属性 | 按不旋转落位，导进来后在编辑器里核对方向 |
| 镜像/翻转的 `transform` | 照常画，但告警提醒「形状方向可能和 CDR 里相反」，请核对 |
| `textLength`（把文字拉伸到指定宽度） | 不认这个宽度，按自然排版，请核对 |

**尺寸填写**：导入窗口里的标签宽高默认取**底稿画布尺寸**（`width`/`height`，没写就按 `viewBox` 推），单位毫米。合法范围 8~600mm。
你把它改成另一个值也行：底图会**按比例缩到标签里并居中，绝不拉伸变形**（窗口里会告诉你缩到了百分之多少）。
真正要是超宽件，切成几份分别导入。一个模板的底图只占 **1 个元素位**，几百个对象也不会撑爆上限；
只有被提升的文字才占元素位（可提升文字上限 60，单模板元素上限 80）。

## 6. 直接拖 `.cdr` 进来能得到什么

LabelGou 能打开 `.cdr` 的**外壳**，拿到里面**自带的那张预览图**：

- 新版（X4+）：`.cdr` 是个 ZIP，里面有 `thumbnail` 条目 → 直接取；
- 老版（X3 及更早）：裸 RIFF 容器，读 `DISP` 块，按 256 色调色板还原成位图。

这张图**只能当对版参照**：256 色索引位图、没有对象、没有毫米坐标、没有文字、没有图层，
文件一大就糊。所以导入后它被标成**只作对齐参考、不可打印**：

- 屏幕上看是淡显的，右下角有角标提醒你这不是要印的东西；
- 打印、导出 PDF/PNG/TIFF/SVG 这几条出口会**自动排除**它，不会混进件子；
- 文字得自己在编辑器里重加一遍，标签宽高也得自己填。

也就是说：`.cdr` 直给的是「照着重建时的参照物」，SVG 给的才是「保真底稿」。

## 7. 编码与合规

- `ExportSvgForLabelGou.bas` 故意存成 **GBK/ANSI**。VBA 编辑器按本机 ANSI 代码页读文件，
  存成 UTF-8 的话中文注释和 `MsgBox` 文字会花屏。**后续编辑请保持同一编码**（记事本另存为时选 ANSI）。
- 本 `README.md` 是 UTF-8。
- 宏全部自写，只使用 CorelDRAW 公开 API 名（API 名是事实，不构成对 GPL 代码的抄袭）；
  调研阶段读过的开源 CDR 工具集（GPL-3.0 / 无许可证）**只读不抄**。

## 8. 反馈问题时需要提供的信息

1. CorelDRAW 版本号（**帮助 → 关于**，例如「CorelDRAW Graphics Suite X4, Version 14.0.0.492」）；
2. 走的哪条路：手动导出 / 宏 / `.cdr` 直开；
3. `导出清单.txt` 全文（宏路），或截图上的报错原文；
4. 导出的那个 `.svg` 的**前 30 行**（用记事本打开复制即可，够我判断单位与结构）；
5. LabelGou 的日志：**帮助 → 查看运行日志**，把最近一段贴过来。
